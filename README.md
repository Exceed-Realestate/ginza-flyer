# 銀座セールスギャラリー — 開業チラシ（B5）

Exceed Real Estate の銀座セールスギャラリー（2026年10月18日開業）の
B5チラシ組版ツール。**18枚の写真 × 4レイアウト = 72通り**を、
主見出し・副見出し・リード文・フェード色と自由に掛け合わせて確認できる。

**Live:** https://exceed-realestate.github.io/ginza-flyer/

## 使い方

上部のセレクタを切り替えるだけ。選択内容は `localStorage` に保存される。

| コントロール | 中身 |
|---|---|
| 画像 | 18枚。名前は写真の中身から付けている（例:「銀座の消失点」「灯」「入口」） |
| レイアウト | 選んだ写真ごとに4案。すべて表示で4案を縦に並べる |
| 主見出し | 6案 |
| 副見出し | 6案 |
| リード文 | 6案 |
| フェード色 | 6色（ネイビー／チャコール／ディープサンド／ディープティール／墨／ブロンズ） |
| ロゴ | デベロッパー4社を社名テキスト⇄白ヌキロゴ |
| 社章 | EXCEED マークの有無 |

## レイアウトの考え方

4案は写真ごとに**手で決めている**。全画像を計測（明度・情報量）したうえで、
どこが本当に空いているか、墨と白のどちらが乗るかを1枚ずつ判断した。

- **1 天** — その写真で最も静かな面に見出しを置く
- **2 地** — 写真には一切触れず、文字を下の帯に集める
- **3 側** — 左右どちらか、空いている側に寄せて余白を作る
- **4 二段** — 見出しは上、4社を左の柱に縦に積む

各画像の判断理由はページ上部（写真名の下）に日本語で表示される。

サイズは B5 片面 182 × 257 mm。入稿時は塗り足し3mm（188 × 263 mm）。
目標は **開業の認知 ＋ LINE友だち追加**（予約獲得ではない）。
